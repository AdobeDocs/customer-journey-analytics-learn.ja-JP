# 日付フィールド機能を活用する

日付フィールドのサポートにより、Customer Journey Analytics 内で日付フィールドおよび日付と時刻のフィールドを扱えるようになります。 日付フィールドまたは日付と時刻のフィールドの表示方法を選択できるほか、含む／除外機能で日付専用の論理演算子を使用して、表示内容をフィルターできます。
