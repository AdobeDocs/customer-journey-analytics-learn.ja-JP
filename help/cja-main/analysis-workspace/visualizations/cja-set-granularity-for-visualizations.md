# ビジュアライゼーションの精度の設定

トレンドのビジュアライゼーション設定の粒度セレクターを使用して、データの表示方法を簡単に調整できます。 この機能は、ニーズに合わせてビジュアライゼーションを絞り込むことで、データ分析を簡素化します。 ワークフローを最適化し、データインサイトをより活用する方法を解説します。
