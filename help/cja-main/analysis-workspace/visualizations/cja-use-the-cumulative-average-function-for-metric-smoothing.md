# 指標のスムージングに累積平均関数を使用する

指標の傾向を示す期間が長いほど、指標の方向の傾向を示すのが難しくなります。 これを解決するために、計算指標の累積平均関数を使用して、Analysis Workspace の指標にスムージングを適用できます。
