# CJAでオブジェクトレベルのセグメント化のためにサブイベントを分析する

[!DNL Customer Journey Analytics]の[!UICONTROL  サブイベント分析]を使用して、より正確なセグメンテーションとレポートを実現する方法を説明します。 オブジェクトレベルのセグメンテーションは、Adobe Experience Platformの拡張可能なデータモデルを活用することで、過剰なアトリビューションを排除し、売上分析を向上させ、複雑なデータセットをまたいでより詳細な調査を可能にします。

詳しくは、[ドキュメント](https://experienceleague.adobe.com/en/docs/analytics-platform/using/cja-components/segments/sub-event){target="_blank"}を参照してください。
